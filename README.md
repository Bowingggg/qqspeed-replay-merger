## 录像版本支持

**兼容范围限定为 v37、v47、符合已适配结构的 v53 和 v55。2011 年的 SAV v12（89 字节早期结构）不支持，并已停止适配和维护。** 不建议为了合并目的使用这一时期的录像。


现在可以直接选择不同年代的 QQ飞车 SAV 录像，只要是同一张地图，就可以把两人的跑图放到一起。

- **v37（2021 年的旧录像）**：已支持单人录像合并。v37 与 v37、v37 与 v55 的合并都已完成游戏内播放测试。
- **v47（2025 年的旧录像）**：已支持单人录像合并。v47 与 v55 的合并结果，三种模式均已完成游戏内播放测试。
- **v53（2026 年的部分录像）**：已能直接合并采用与 v55 相同运动帧、玩家与事件结构的单人录像。2026 年的 v53 与 v55 合并，三种模式已经通过游戏内播放验证。v53 也有其他旧结构；缺少可恢复的实体/事件数据时仍会拒绝，不把这些文件误当成损坏的 v55。
- **v55（较新录像）**：维持原有单人及多人录像支持，可从多人录像中指定玩家。

v37 / v47 / 符合结构要求的 v53 与 v55 可以跨版本组合，但仍然要求**两份录像的地图一致**。旧版的运动记录和现在的格式不同，软件会在内存中自动转换，玩家无需手动修改 SAV 或更换文件扩展名；原始录像不会被覆盖。

这里说的是 **SAV 文件内部版本号**，不是 QQ飞车客户端版本、Windows 版本，也不是软件自身的 v0.8.13 版本号。**v54 等尚未适配的 SAV 版本不在支持范围内**，v53 也只在结构匹配时可用。选到这些文件时，会直接提示检测到的实际版本号及支持列表，不会只说“格式错误”。

这些是 v0.8.12 起的兼容范围。详细解释见 [功能说明](FEATURES.md)。

## 这个软件是做什么的

你和朋友各跑一局同一张地图，把两份单人录像交给它，它会把你俩的跑图轨迹放进同一份双人录像里。合并出来的录像在游戏里是双人回放：两辆车同时出现在同一条赛道上，你可以看着两段跑图并排跑完。

适合拿来复盘对局、对比跑法、做对比视频，或者只是想在游戏里"同框"跑一次。

## 三种合并方式

| 方式 | 画面效果 | 适合谁 |
| --- | --- | --- |
| **同时起步** | 把两人真正开始移动的那一刻对齐，之后各跑各的，快的一方先到终点 | 想看清"纯跑图差距" |
| **同时过线** | 快的车会在起步处等一会儿，让两车一起冲线 | 想看并排冲线的画面 |
| **皮筋式拉回** | 落后太多时，领先的车会被拉回到之前的画面，双方都能被拉 | 想让两车全程贴在一起跑 |

界面默认选的是「皮筋式拉回」，可以随时切换。三种方式的原理和细节见 [FEATURES.md](FEATURES.md)。

## 核心功能

- **两份录像合并**：同地图的两份录像 → 一份双人回放录像；v37 / v47 单人、已适配的 v53 及 v55 单人/多人可混合使用。
- **多人录像也能用**：从 1～6 人的录像里指定具体玩家，按昵称和成绩挑选。
- **三种合并方式**：同时起步、同时过线、皮筋式拉回（阈值可调）。
- **副视角时间轴修复**：处理网络影子的异常时钟。v55 原有备用时钟处理保持不变；现在也能识别 v47 / v53 的辅助时钟，并对没有辅助时钟的 v37 进行有界估计修复。旧版多人样本仍待实机确认。
- **保留原车 / 换成板车**：默认保留原车型和外改，也可以勾选统一换成板车外观。
- **同地图校验**：第二份录像只能从同地图录像里选，选错会被拦住。
- **不覆盖文件**：输出自动命名，重名自动加序号，原录像永远不会被改动。
- **录像简介**：可以给合并出来的录像写一句简介，不填就自动用输出文件名；也能单独给已有的录像改简介，原文件不动。
- **写后回读校验**：文件写进磁盘后重新读回来核对，确认无误才算完成。
- **完全离线**：不需要账号、密码或网络。

完整说明（含每种功能为什么需要、怎么实现、有什么限制）见 **[FEATURES.md](FEATURES.md)**。

## 使用方法

1. 下载上面的 EXE，放到任意文件夹，双击运行。
2. 点「玩家 1 录像」的「浏览…」选第一份录像；再选「玩家 2 录像」（这里只会列出同地图的录像）。
3. 如果是多人录像，在「玩家 1 选择 / 玩家 2 选择」下拉里挑具体玩家（下拉里显示昵称和成绩）。
4. 选「保存到」目录，选播放方式。
5. 想给录像写简介就在「简介」里输入；留空则自动用输出文件名。
6. 点「开始合并」。

状态栏会依次显示读取、合并、写入、校验的进度提示，完成后显示输出路径。

- 64 位 Windows 系统，双击即用，不需要安装 Python 或任何依赖。
- 不联网、不需要账号和密码，录像只在本机处理。

## 常见问题

**打开时提示"Windows 已保护你的电脑"？**
程序没有购买数字签名证书，Windows 会对陌生程序给信誉提示。点「更多信息」→「仍要运行」即可。这类提示不是病毒警告。

**为什么合并后昵称变成「合并器_1」「合并器_2」？**
合并用的是程序内置的一份底板，昵称必须固定，否则容易和原录像的身份、成绩冲突，所以统一改名为「合并器_1」「合并器_2」。你的真实昵称只用在输出文件名上。

**为什么地图名显示成「地图137」这种编号？**
程序内置了 7 张常见地图的中文名，其它地图照样能合并，只是文件名里用地图编号代替名称。

**为什么有些录像提示不支持某个版本，或 v53 的部分结构？**
SAV 文件有自己的内部版本，不同年代记录的每帧内容可能不同。当前经过适配与验证的是 v37、v47 单人录像、符合已适配结构的 v53，以及 v55 单人/多人录像。v54 等其他版本会显示实际检测到的版本号；部分 v53 旧结构也会明确提示缺少可恢复数据；并不是直接把文件头数字改成 v55 就能用。

**两份录像不在同一张地图怎么办？**
合并不了。选择第二份录像时，程序只会列出同地图的录像；地图不同会直接提示「两份录像必须属于同一地图」。

**合并出来的录像在游戏里放不出来？**
离线验证和实际游戏加载不完全等价。如果遇到加载失败，请保留原录像和合并结果，方便排查。

**能不能自己换底板、换车、改昵称、改装备？**
不能，这些都是固定的：底板决定录像能不能被游戏正常加载，改动的余地很小。唯一可选的是「替换车型为板车」这个选项。

**「简介」是干什么用的？**
写进录像简介字段的一句话说明。留空时自动使用输出文件名；输入文字就按你写的保存。旁边的「修改录像简介…」可以单独给已有录像改简介，生成一份副本，原文件不会被改动。文字使用 GBK 编码，最多 127 字节（纯中文一般 60 多字）。

**保存目录里有同名文件会被覆盖吗？**
不会。第一份叫原名，之后再生成就自动加 `_002`、`_003`，原录像文件一个字节都不会被改写。
